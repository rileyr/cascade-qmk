# AZIO Cascade Slim

75% low-profile keyboard on a Sonix SN32F248B, per-key RGB. Pinout recovered from the stock
firmware and verified on hardware; see the parent repository's docs/PINOUT.md.

- Keymaps: `default` (Fn layer, custom effects, VIA), `debug` (QMK console + matrix debug),
  `probe` (every key types its matrix row.col; hold Esc while plugging in for the bootloader).
- Bootloader: Sonix ISP in ROM. From QMK, Fn+Esc (`QK_BOOT`). From stock firmware, short the two
  right-most of the five pads left of the spacebar switch while plugging in.
- Flash: `tools/cascade_flash.py` in the parent repository, or SonixQMK's flasher, offset 0.
- Bluetooth: not implemented (separate CYW20730 module on SPI0); wired only.

`keyboard.json` and `keymaps/default/keymap.c` are generated by `tools/gen_board.py`.
